# v1.2.0 公开发布验证

日期：2026-10-25（Asia/Shanghai）。

## 已执行

- Windows 本机 Python 3.12.14、psutil 7.2.2。
- 从公开源码目录运行 `python -m unittest discover -s . -p "test_*.py" -v`。
- 最新快照发现 289 项测试：288 项通过，1 项显式跳过，无失败/错误，包含新增的停用控制测试。
- 跳过项为需设置 `LOCAL_MODEL_LITE_INTEROP=1`、安装 MCP SDK 并连接已运行管家的可选真实 SDK 互操作测试；不能把跳过当作通过。
- 覆盖内容包括任务准入、保护恢复、资源预算、忙碌/身份变化拒绝停止、清单登记与回滚、学习反馈、MCP 输入校验和闲置应用回收保护。
- 用独立目录、随机 loopback 端口和空模型配置验证首次启动、状态查询及正常关闭；未启动模型。
- `smoke_app_memory.py` 仅处理它自身创建的测试子进程：回收前后私有提交量均约 138.76 MiB，重新访问数据后 SHA-256 不变，子进程保持存活；错误身份与取消条件被拒绝。这不能代表实际应用的主观使用体验。
- 对公开文件进行凭证常见格式、个人路径、私有数据类型扫描，并检查 Python 语法、JSON 与 Markdown 本地链接。25 个运行/人工 smoke 模块与安装快照按字节一致。

## 验证边界

默认测试使用模拟后端与临时状态，不启动实际 H3/Muse，不执行模型推理，也不回收用户正在使用的应用。此次发布不以真实模型生命周期 smoke 测试影响已有工作。

没有据此宣称跨硬件性能、所有后端兼容性、消除 OOM、人工桌面流畅度或生成画质保证。实验性 Qwen2-Audio worker 不属于上述正式集成验证范围。

可复现命令与测试夹具随仓库发布；GitHub Actions 在 Windows/Python 3.12 上运行同一默认单元测试集合。CI 是否通过以仓库实际运行结果为准。
